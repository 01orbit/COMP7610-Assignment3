\textbf{System design.}
\code{CPT} is an OpenZeppelin ERC-20 token with 18 decimals. Deployment mints exactly 1,000 CPT to the CPT contract as the club treasury. Only \code{ADMIN_ROLE} can call \code{mintPoints} (new points), \code{distributePoints} (treasury points), or \code{adminBurnPoints} (permanently deduct a specified amount from a user's balance). Standard \code{transfer}, \code{approve}, and \code{transferFrom} remain available to users.

Members call \code{applyForMembership}; an administrator calls \code{approveMembership}, which grants membership and transfers a fixed 50 CPT welcome allocation from the treasury. A member can call \code{withdrawFromClub} to burn all remaining CPT and revoke membership. Existing NFTs are not destroyed. This is the additional custom withdrawal function.

Administrators can also call \code{adminRecoverPoints(account, amount)} to return existing CPT to the contract treasury without user approval. Recovery preserves total supply, membership, and NFT ownership; recovered CPT can be redistributed.

\code{CampusMemo} is an ERC-721 collection named ``Campus-Memo''. Its maximum supply is 10 and minting costs 100 CPT. Only CPT administrators can issue NFTs: the administrator approves 100 CPT and calls \code{mintMemo(memberAddress)}. The recipient must be a member; 100 CPT is burned from the administrator, while the recipient's balance is unchanged. There is no NFT burn or administrator recovery function. Token IDs start at 1. The constructor stores one commit-pinned GitHub Raw image URL, and \code{tokenURI(id)} generates the JSON on-chain and returns a \code{data:application/json;base64,...} URI. No Gist or external JSON files are required. An owner can call \code{listMemo(tokenId, price)} to escrow an NFT, while a buyer approves the marketplace for the CPT price and calls \code{buyMemo}; CPT is paid to the seller and the NFT is transferred to the buyer. The seller can cancel with \code{cancelMemoListing}.

\textbf{Sepolia deployment (Hardhat).}
\begin{enumerate}
  \item In MetaMask select Sepolia and obtain test ETH. Never use a mainnet private key.
  \item Set environment variables locally (do not commit them):
\begin{verbatim}
export SEPOLIA_RPC_URL="<RPC URL>"
export DEPLOYER_PRIVATE_KEY="<test-wallet private key>"
export NFT_IMAGE_URL="<full commit-pinned GitHub Raw image URL>"
\end{verbatim}
  \item Run \code{npm run compile}, then \code{npm test}, then \code{npm run deploy:sepolia}.
  \item Record the printed addresses and deployment transaction hashes. Verify both addresses on \href{https://sepolia.etherscan.io}{Sepolia Etherscan}.
\end{enumerate}

\begin{enumerate}
  \item Open the two Solidity files in Remix (OpenZeppelin 5.0.2); compile with Solidity 0.8.24, optimizer 200 and EVM paris, use a supported wallet connection (or Browser Extension in Remix web), and confirm Sepolia.

  \item As administrator distribute 100 CPT to the admin account. In CPT call \code{approve} with the NFT address and amount \code{100000000000000000000}, then in CampusMemo call \code{mintMemo(student)}. Confirm ordinary-member minting reverts and the administrator pays 100 CPT. Confirm \code{ownerOf(1)} and \code{tokenURI(1)}.
  \item From the student account call \code{transfer} to another account and \code{safeTransferFrom} for token 1. Confirm both new balances/owners.
  \item As the NFT owner call \code{listMemo(1, price)}. From a buyer account approve the Campus-Memo contract to spend that CPT amount, then call \code{buyMemo(1)}. Confirm CPT reaches the seller and \code{ownerOf(1)} becomes the buyer. A seller can use \code{cancelMemoListing(1)} before purchase.
  \item First return token 1 to the member. That member calls \code{withdrawFromClub()}. Confirm a zero CPT balance, \code{isMember=false}, a \code{MemberWithdrawn} event, and unchanged NFT ownership: \code{ownerOf(1)} is still the former member.
\end{enumerate}
